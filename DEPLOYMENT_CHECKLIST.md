# Deployment checklist

- [ ] Create a new **public** GitHub repository.
- [ ] Upload this project's `docs` folder and `README.md` to `main`.
- [ ] Configure **Settings → Pages → Deploy from a branch → main → /docs**.
- [ ] Open the published home, SHIPDESK, and LabelOnZeWay URLs.
- [ ] Install LabelOnZeWay on an Android or iPhone test device.
- [ ] Download and extract the POS80C gateway kit.
- [ ] Run the gateway's one-time configuration with the final username/repository.
- [ ] Enter the printer's private IP and raw TCP port (normally 9100).
- [ ] Test system printing.
- [ ] Test direct printing and verify a cut after each label.
- [ ] Download a test backup and store it outside the public repository.

Do not upload live customer data, backups, reports, credentials, or printer configuration to the public repository.
