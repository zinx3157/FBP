Print guide

System print or direct POS80C.

System printing works without a gateway. Direct printing sends ESC/POS raster data to the POS80C over your private network and automatically cuts after every selected label.

Normal browser / system print

Choose System / browser print in Settings. On iPhone or iPad this opens AirPrint; Android opens the configured print service; desktop browsers open their normal print dialog. The manifest includes dedicated condensed 80 mm and full A4 formats where available.

Direct POS80C setup

Download gateway kit
Extract the ZIP on the Mac or Windows PC.The computer and POS80C must be reachable on the same private network.
Start the preconfigured gateway.macOS: double-click Start_Hosted_POS80C_Gateway.command. Windows: double-click Start_Hosted_POS80C_Gateway.bat. If macOS blocks it, Control-click/right-click and choose Open. The package is preconfigured for https://zinx3157.github.io/FBP/.
Open the correct route.SHIPDESK on the computer can use http://127.0.0.1:8765. On iPhone/iPad, open the local http://COMPUTER_LAN_IP:8765/labelonzeway/ address printed by the gateway.
Configure the POS80C.In the local LabelOnZeWay app, keep gateway URL on auto, enter the printer IP and port 9100, save, use TEST GATEWAY, then PRINT + CUT TEST.
Keep the gateway window open. A browser cannot connect directly to raw printer TCP port 9100. The local gateway is required whenever Direct ESC/POS mode is selected.

iPhone / iPad dependable direct-print route

Start the gateway and read the Phone local site address shown in its window. On the iPhone/iPad, while connected to the same Wi-Fi, open http://COMPUTER_LAN_IP:8765/labelonzeway/. This local route avoids Safari's hosted-HTTPS-to-local-HTTP limitation. AirPrint remains available from the public Pages app.

  • The gateway accepts only private/local printer destinations.
  • The gateway kit is preconfigured for the exact origin https://zinx3157.github.io, not a broad wildcard.
  • If direct access is blocked, use system printing or the local-site route; data export and backup remain available.
