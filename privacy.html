Privacy notice

Local-first by design.

SHIPDESK and LabelOnZeWay are static browser applications. This GitHub Pages site has no application database and no account sign-in.

Where records are stored

Profiles, customers, parcels, payments, manifests, archives, settings, and retained label copies are stored in browser storage on the device and browser profile you use. They are not automatically synchronized to another device.

Printing

System printing is handled by your browser and operating system. In Direct mode, the browser sends ESC/POS print data to the local gateway address you configure. The gateway forwards those bytes to the private-network POS80C address; it does not upload them to GitHub.

Backups and device clearing

You are responsible for downloading regular backups. Clearing site data, resetting the app, using private browsing, or removing a browser profile can delete local records. Restore files only from a source you trust.

Public hosting

Do not put live customer backups, exported manifests, credentials, printer addresses, or other confidential operational files into the public GitHub repository. The deployment kit contains application code and placeholder configuration only.

Third-party platform

GitHub may process ordinary hosting logs and network metadata under its own policies when serving GitHub Pages. The applications themselves do not include analytics in this package.
